Dev run (requires Python + repo checkout, not a distributable build):

  cd /d "C:\Users\win10\Downloads\mac2 (2)\mac2\desktop"
  npm install
  npm run tauri:dev

  Engine starts automatically from repo root (python run_desktop_api.py).

Phase 1 desktop features (history delete/print, PDF export, startup alerts,
Firebase sync on launch) require API revision 20+.

Phase 2 desktop features (returns save, general products CRUD, reorder →
purchase prefill) require API revision 21+ — rebuild engine + Tauri after
pulling these changes.

Phase 3 desktop features (live sync footer, bulk purchase return, reorder by
supplier editor, license activation gate) require API revision 22+ — rebuild
engine + Tauri after pulling these changes.

Phase 4 desktop features (app login gate, PDF on save, bill preview/history
PDF, inventory bulk actions, mobile import UI, purchase import review, Drive
restore) require API revision 30+ — rebuild engine + Tauri after pulling.

Manual Tauri-only build (without engine sidecar — not for distribution):

  cd /d "C:\Users\win10\Downloads\mac2 (2)\mac2\desktop"
