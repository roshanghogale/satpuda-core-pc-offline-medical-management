# Alert and Monitoring (Settings)

Notebook tabs inside this screen:
- Low Stock: medicines below threshold; Reorder action
- Out of Stock: zero stock items
- Expired: batches past expiry; Return action
- Near Expiry: expiring soon
- Schedule Report: scheduled drug movement exports

Each tab lists medicines; export or jump to Reorder/Returns from action buttons.

Startup alerts on Home may mirror these lists.
