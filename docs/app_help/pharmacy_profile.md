# Pharmacy Profile (Settings)

Sections in the left panel:

## Profile
Store name, address, phone, GSTIN, drug license, logo. Shown on printed bills.

## Bill Print Style
Invoice layout, paper size, copies, margins, header/footer, Print Sales 1 and 2 presets (F7/F8 behavior).

## Doctor fields
Require doctor name on bills for scheduled medicines (H, H1, X).

## UPI / QR
UPI ID for payment QR on bills (also in Sales and Billing settings).

Save each section with its Save button inside the app.
