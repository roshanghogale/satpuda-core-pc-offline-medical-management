# Inventory

One scrollable page. Search and Filter panel applies filters LIVE (no Apply Filter button). Ctrl+Shift+C clears filters.

## Search and Filter
Search, Type, Stock Status (In Stock/Low/Out of Stock), Expiry Status (Near Expiry/Expired), Schedule, Refresh, Export, Delete Zero Stock.

## List actions
- Edit Medicine — dialog, Save Changes commits to DB
- View Details — read-only dialog (double-click)
- Reorder — opens Settings Reorder with prefill
- Delete Medicine — hides batch; sales/purchase history kept

## Export
Export button: Current View (filtered), Stock Statement (all), Near Expiry, Expired Stock, Schedule-wise Stock.

Never say Apply Filter on Inventory.
