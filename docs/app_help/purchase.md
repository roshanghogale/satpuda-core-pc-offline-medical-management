# Purchase

Multi-tab supplier stock-in on ONE screen. Inventory increases when you save the purchase bill.

## Screen layout (everything on one page)
- **Supplier Information** (left): supplier and bill header fields — all visible, no popup.
- **Medicine Details** (right): all medicine fields — all visible, no popup.
- Items table below, then **Purchase Summary** and **Save Purchase (F5)**.

## Important — no Add New tab button
- **Purchase 1** tab is already open when you arrive.
- Another tab: **Ctrl+Shift+N**. Close tab: **Ctrl+Shift+W**.
- From **Home** only: **New Purchase** quick action (not on the Purchase page).

## Supplier Information panel (left, inline)
- **Supplier Name:** searchable — type or pick. **NO Add, +, or separate Save.**
- **Address**, **Phone**, **GSTIN**, **DL Numbers**, **Purchase Date**, **Bill Number**

### Existing supplier
1. Pick or type name in **Supplier Name**.
2. Other fields load automatically.

### New supplier
1. Type new name in **Supplier Name** (same panel).
2. Fill Address, Phone, GSTIN, DL in the same panel.
3. Add medicine lines, then **Save Purchase (F5)** — supplier and bill save together.

## Medicine Details panel (right, inline)
Visible fields include:
- **Medicine Name**, **Type**
- **Quantity Details** (Strips/Qty, Tablets/Strip, Free Strips — or units for liquid types)
- **HSN Code**, **GST %**, **MRP**, **Rate (per strip/unit)**, **Manufacturer**
- **Batch No**, **Expiry (MM/YY)**, **Schedule**, **Content/Drug**, **Discount %**
- **Add Medicine** button

### Add a medicine line (correct flow)
1. In **Medicine Details** (right panel), type or select **Medicine Name**.
2. Choose **Type**; qty fields update for that type.
3. Fill batch, expiry, rate, MRP, manufacturer, qty, etc. in the same panel.
4. Click **Add Medicine** — the filled row moves to the items table below. **No new window opens.**
5. Medicine fields clear for the next line; repeat.
6. When done, click **Save Purchase (F5)**.

**Add Medicine** adds the current filled row to the bill list. It is NOT a button to open a medicine registration dialog.

New medicine names: type in **Medicine Name**, fill details on the same screen, Add Medicine, then save the whole bill with F5.

## Save
- **Save Purchase (F5)** — supplier (create if new), bill, and stock.
- Stock does NOT increase when you only click Add Medicine.

Never mention popup/window for supplier or medicine. Never mention + button for supplier.
