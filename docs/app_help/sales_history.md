# Sales History

## Filter Options
From Date, To Date, Fin Year, Customer, Due, Schedule, Sort By.
Apply Filter — REQUIRED for date range. Customer/Due/Schedule may auto-apply on select.

Buttons: Apply Filter, Clear Filter, Export, Print All (paper size from settings).

## Bill actions
View Bill Details (read-only dialog), Edit Bill (fullscreen Update Sale F5), Print, Delete (irreversible, restores stock).

## Export
Current View (with filters), Sales Register, Monthly/Daily Summary, Customer Due, Doctor-wise, Payment Mode, Schedule Report (extra dialog).

Summary Total Due (All Time) is global customer dues — not filtered by bill list.
