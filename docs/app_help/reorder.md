# Reorder

Settings — Reorder tab (also from Inventory context Reorder).

## Views
Pending Orders: Active/Received, Edit, Receive, Cancel.
New Order: supplier tabs (+ Supplier), medicine/pack/qty, Save Draft, Mark Ordered.

## Receive flow
Receive dialog: add stock on Purchase page first, Open Purchase, then Mark Received.
Mark Received only clears pending order — does NOT add stock.

Load by Supplier: bulk tabs for low/out-of-stock items.
Reorder Defaults dialog: minimum stock and default order qty per type.
