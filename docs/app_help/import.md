# Import (Settings)

Sections:
- Purchase Bill Import: scan/photo bill with Gemini AI to fill purchase lines
- Web Entry: supplier web portal entry
- Import Data: JSON bulk medicine/purchase import
- Mobile Import: sync from mobile app

Gemini API key is configured here once for bill photo import and Satpuda AI tutor (same key).

Enable Gemini AI checkbox and Save key in this tab. Satpuda AI uses the existing key automatically when App Tutor is enabled under My Assist.
