# Export reports and filters

## Shared export flow
1. Click Export (or Home quick export buttons)
2. Pick report name in list dialog
3. Pick format: CSV, Excel (.xlsx), PDF (HTML)
4. Save file dialog

Current View exports use on-screen visible columns and active filters.

## Home quick actions (if enabled in Appearance)
Export Sales, Export Purchases, Export Inventory, Export All — same backend as Data and System Export Data.
Keyboard: E or Ctrl+E opens export menu on Home.

## Data and System — Export Data
Inline default format radios: CSV, Excel, PDF.
Buttons: Export Sales, Export Purchases, Export Inventory, Export All (full database extracts, no report picker).

## Sales History — Export
Filter Options: From Date, To Date, Fin Year, Customer, Due, Schedule, Sort By.
Click Apply Filter after date range (Fin Year auto-applies).
Export reports:
- Current View (with filters)
- Sales Register (all bills) — uses From/To
- Monthly Summary, Daily Sales Summary
- Customer Due Report (all dues, no date)
- Doctor-wise Sales, Payment Mode Report
- Schedule Report — extra dialog for period and schedule checkboxes

## Purchase History — Export
Same filter bar pattern with Supplier, Status instead of Customer, Due.
Reports: Current View, Purchase Register, Monthly Summary, Supplier Due Report, GST Purchase Report.

## Inventory — Export
Search and Filter: Search, Type, Stock Status, Expiry Status, Schedule — live filters (no Apply).
Reports: Current View (filtered), Stock Statement (all), Near Expiry Report, Expired Stock Report, Schedule-wise Stock.

## Contacts — Customers — Export
Current View (filtered), Customer List (all), Customer Due List.

## Alert and Monitoring
Per sub-tab Export exports filtered rows in that alert list.

## Layout and Lists — Column Visibility
Export report columns section configures which columns appear in named reports (not the runtime export menu labels).
