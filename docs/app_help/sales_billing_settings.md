# Sales and Billing settings (Settings tab)

Sections:
- Sales Screen: payment mode field (Cash/Due), field position
- Batch Picker: how batch selection works when adding medicines
- Sales Return: defaults for return screen
- Sales Bill Save: PDF folder for saved bill copies
- UPI Payment QR: QR on printed bill
- Autosave: draft bill autosave behavior

These control the Sales screen behavior, not Satpuda AI.
