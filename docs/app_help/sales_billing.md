# Sales (Billing)

Multi-tab customer invoices on ONE screen. Stock decreases when you save the bill.

## Screen layout (everything on one page)
- **Customer Information** panel — all customer/doctor fields inline, no popup.
- **Medicine Selection** panel — Medicine, Quantity, Disc, **Add Medicine** inline.
- **Selected Medicines** table, totals, **Save Sales (F5)**.

## Important — no Add New tab button
- **Sale 1** tab is already open when you arrive.
- Another tab: **Ctrl+Shift+N**. Close tab: **Ctrl+Shift+W**.
- From **Home** only: **+ New Bill** (not on the Sales page).

## Customer Information (inline)
- **Customer Name** — searchable. **NO Add, +, or separate Save.**
- Phone, Address (Village), Doctor, Payment, Bill Date — same panel.

### New customer
1. Type name in **Customer Name** on the same screen.
2. Fill phone/address as needed in the same panel.
3. Add medicine lines, **Save Sales (F5)** — customer and bill save together.

## Medicine Selection (inline)
- **Medicine** — search and pick stock item.
- **Quantity**, **Disc**
- **Add Medicine** (green)

### Add a medicine line (correct flow)
1. Select medicine in **Medicine** field (same panel).
2. Enter **Quantity** (and **Disc** if needed).
3. Click **Add Medicine** — line appears in **Selected Medicines** table. **No dialog for normal billing.**
4. Repeat; then **Save Sales (F5)**.

**Add Medicine** adds the selected medicine with qty to the bill. It does NOT open a window to create a new medicine.

If multiple batches exist, the app may show a small batch picker — that is choosing stock, not adding a new medicine master.

## Main buttons
| Save Sales (F5) | F5 |
| Clear Form | Ctrl+Shift+C |
| Add No Stock | Ctrl+Shift+M (special — only for selling without stock) |

Never mention popup/window for customer or medicine on normal billing.
