# Home dashboard

## Dashboard stats (footer)
When enabled: today sales, month sales, financial year totals, bill counts. Refreshes when you return to Home.

## Quick Actions (left column)
Configurable in Settings - Appearance - Quick Access:
- New Bill -> Sales
- New Purchase -> Purchase
- Search Medicine -> Inventory
- Contacts -> Settings - Contacts
- Ledger -> Settings - Ledger
- Export Sales / Purchases / Inventory / All
- Alerts -> Settings - Alert and Monitoring
- General Products

## Banner (right)
Promotional image from Settings - Appearance - Home Banner.

## Keyboard (on Home)
| Key | Action |
| B | New Bill (Sales) |
| P | New Purchase |
| I | Inventory |
| E / Ctrl+E | Export menu |
| F2 | Focus quick actions |

## Satpuda AI
Floating **?** button (bottom-right) opens **Satpuda AI** chat. Ask about workflows and screen steps.
