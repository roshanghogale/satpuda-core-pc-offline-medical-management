# Settings — all tabs and sections

13 tabs in order: Pharmacy Profile, Contacts, Shelf Management, Appearance, Layout and Lists, Sales and Billing, Import, Alert and Monitoring, Data and System, Payment, Ledger, Reorder, Shortcuts.

Lazy tabs (load on first open): Sales and Billing, Import, Alert and Monitoring, Data and System, Reorder.

Ctrl+Tab cycles tabs. F4 focuses left Sections sidebar where present.

## Pharmacy Profile — Sections
Pharmacy Profile (store fields, Save Profile), Bill Template, Bill Fields, Bill Text Lines, Bill Logo, Paper and Copies, Sales Print Buttons, Printer Setup.

## Contacts — Sections
Doctors (Add Doctor), Customers (search, Recalculate All Dues, Export), Villages, Suppliers (list only — no Add button; edit via context menu).

## Shelf Management
Rack/shelf labels for inventory Location column.

## Appearance — Sections
Theme (Apply Theme restarts), Font Size, Home Banner, Quick Access checkboxes (New Bill, New Purchase, exports, Alerts, etc.), Dashboard Sections.
Save Appearance and Restart (F10) on sidebar.

## Layout and Lists — Sections
Column Visibility (on-screen and export columns), Table Row Counts, Medicine Types, Medicine Units, Schedules, Thresholds and Reorder, Sales Margin Display, Record Indicators, App Mode (Medical/Veterinary).

## Sales and Billing — Sections
Sales Screen Layout, Batch Picker, Sales Return lookup days, Sales Bill Save, UPI QR, Autosave.

## Import — Sections
Purchase Bill (Import Purchase Bill button), Web Entry, Import Data (JSON file/paste), Mobile Import, Gemini AI key (same key as Satpuda AI).

## Alert and Monitoring — Sub-tabs
Low Stock, Out of Stock, Expired, Near Expiry, Customer Dues.
Actions vary: Reorder, Return, Remove from List, Remove All Expired (Expired tab).
Refresh All at top.

## Data and System — Sections
Stores and Startup Alerts, Export Data, Google Drive Backup, App Updates, My Assist (Satpuda voice + Enable Satpuda AI), Administrator, Danger Zone.
Alias in shortcuts: Management = Data and System.

## Payment — Toggle bar
Supplier Payment (default): supplier, Amount Paid, Payment Mode, Save Payment (F5), Payment History.
Customer Payment: Cash/Online split, Save Payment (F5).

## Ledger — Toggle bar
Supplier Ledger / Customer Ledger: name, From/To, View Report, Reset. Bank-statement style tree.

## Reorder — Top bar
Pending Orders, New Order, Load by Supplier, Reorder Defaults dialog.
Pending: Edit, Receive (Open Purchase then Mark Received), Cancel.
New Order: supplier tabs, Add medicines, Save Draft, Mark Ordered.

## Shortcuts
Read-only keyboard reference for entire app.
