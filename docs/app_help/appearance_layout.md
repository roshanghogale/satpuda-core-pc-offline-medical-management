# Appearance and Layout (Settings)

## Appearance tab sections
- Theme: light/dark ttkbootstrap themes
- Font Size: app-wide text size
- Home Banner: image on Home screen
- Quick Access: which Home quick action buttons show
- Dashboard Sections: show/hide Home stats footer

## Layout and Lists tab sections
- Column Visibility: show/hide table columns per screen
- Table Row Counts: rows visible per page
- Medicine Units: strip, bottle, etc.
- Schedules: H, H1, X drug schedule labels
- Medicine Types: categories
- Thresholds: low-stock alert levels
- App Mode: medical vs general product emphasis

Changes apply after Save in each section.
