# Voice and keyboard

## Satpuda (nav bar)
Local Whisper voice control. Wake word in My Assist settings.
Opens screens: home, sales, purchase, inventory, histories, returns, settings tabs.
Does not answer how-to questions - use Satpuda AI for that.

## Satpuda AI (floating ? button)
Gemini tutor. Text or Mic for one-shot question.
Read-only: never changes data. Uses existing Gemini key from Import settings.

## Common shortcuts
| F5 / Ctrl+G | Save sales |
| F7 / F8 | Save + print sales |
| Ctrl+Shift+N | New sales tab |
| Ctrl+E | Export menu |
| F2 | Focus main list |

Full list: Settings - Shortcuts tab.
