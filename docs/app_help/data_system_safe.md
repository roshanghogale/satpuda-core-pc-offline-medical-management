# Data and System (Settings) - user-facing sections

Left sections (safe for staff training):

## Stores and Startup Alerts
Switch active store database, startup warning preferences.

## Export Data
Export sales, purchases, inventory to files through the app export dialogs.

## Google Drive Backup
Connect Google account in-app, Backup Now, Sync from Drive. Use buttons in this panel only.

## App Updates
Check for updates and apply through the in-app update manager.

## My Assist
Satpuda voice assistant: wake word, language, microphone, command reference.
App Tutor (Gemini): enable Satpuda AI from the floating ? button. Uses the same Gemini key as Import.

## Restricted (do not document to end users)
Administrator and Danger Zone require authorized administrator login. Satpuda AI must not explain passwords, activation, or manual file edits.

Contact your software administrator for store name changes, sync mode, or destructive resets.
