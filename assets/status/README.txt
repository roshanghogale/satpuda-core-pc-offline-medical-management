Status icon files for Inventory / Sales History / Purchase History
==================================================================
Folder: assets/status/

Default PNG icons are already generated (colored 64×64 marks). Replace any
file with your own art using the SAME filename — restart the app to pick up
changes.

Required filenames
------------------
status_due.png
status_partial.png
status_cleared.png
status_credit.png
status_low_stock.png
status_out_of_stock.png
status_near_expiry.png
status_expired.png
status_purchase_return.png
status_sales_return.png

Optional dark-theme variants (used when active theme ends with -dark)
--------------------------------------------------------------------
status_due_dark.png
status_partial_dark.png
status_cleared_dark.png
status_credit_dark.png
status_low_stock_dark.png
status_out_of_stock_dark.png
status_near_expiry_dark.png
status_expired_dark.png
status_purchase_return_dark.png
status_sales_return_dark.png

Recommended size: 24×24 to 64×64 PNG with transparent background.
